# Curriculum proposal

## Context

This proposal provides a collection of supervised side projects designed to complement the AR/VR specialization curriculum.

The objective of these projects is to encourage students to build polished, portfolio-oriented prototypes alongside the official curriculum projects.

While the specialization already introduces important technical concepts related to game development, 3D environments and interactive systems, these additional projects aim to provide students with more opportunities to:

- Practice gameplay programming.
- Improve project organization.
- Experiment with game feel and interaction design.
- Build complete and presentable prototypes.
- Strengthen their technical portfolio.

The repository is designed as a practical and progressive learning environment focused on production-oriented skills and real-world project presentation.

Students are encouraged to publish their work on platforms such as [Itch.io](https://itch.io/) and GitHub in order to progressively build a professional portfolio throughout the specialization.

## Educational approach

The educational approach focuses on hands-on learning through small but polished gameplay prototypes.

Rather than building large-scale games, students will work on focused vertical slices designed to strengthen specific technical and gameplay programming skills.

Each project introduces different development challenges such as:

- Player movement systems.
- Collisions and physics.
- Gameplay feedback.
- UI systems.
- Enemy behaviors.
- Procedural systems.
- Optimization.
- Level design.
- Gameplay polish.

The objective is to help students understand the importance of iteration, readability, responsiveness and overall player experience.

Special attention is also given to project presentation and portfolio quality.

At the end of the specialization, students should not only understand technical concepts, but also be able to showcase concrete and playable projects demonstrating their skills in gameplay programming and interactive application development.
