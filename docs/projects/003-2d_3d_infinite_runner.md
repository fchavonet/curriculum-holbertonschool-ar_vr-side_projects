# 2D/3D infinite runner (mobile oriented)

## Description

Students will develop a mobile-oriented endless runner game in 2D or 3D.

The game will feature lane switching, obstacle generation, score progression and increasing speed over time.

Depending on the chosen visual direction, students may focus on either stylized 2D readability or immersive 3D presentation.

The focus of the project is accessibility, optimization and mobile gameplay readability.

## Learning objectives

- Understand gameplay architecture for 2D and 3D games.
- Implement procedural obstacle generation.
- Learn mobile gameplay constraints.
- Optimize rendering and performance.
- Manage game pacing and difficulty progression.
- Build clean UI systems for score and menus.

## Technical requirements

### Mandatory features

- Endless gameplay loop.
- Lane switching system.
- Procedural obstacle spawning.
- Score system.
- Increasing game speed.
- Main menu.
- Restart system.
- Mobile-oriented controls.

### Bonus features

- Character skins.
- Dynamic environments.
- Day/night cycle.
- Object pooling optimization.
- Mobile haptic feedback.
- Collectibles.
- Achievement system.

## Why this project matters

This project introduces students to production constraints commonly found in mobile development.

It showcases:

- Optimization awareness.
- Procedural systems.
- Gameplay pacing.
- Accessibility-focused design.
- Scalable gameplay architecture.
- Mobile gameplay readability.

## How to present it in recruitment

Students should describe the project as:

> A mobile-oriented endless runner prototype focused on procedural generation, optimization and scalable gameplay systems.

- Smooth performance.
- Gameplay readability.
- Procedural obstacle spawning.
- Clean mobile UX.
