# 3D infinite runner (mobile oriented)

## Description

Students will develop a mobile-oriented endless runner game in 3D.

The game will feature lane switching, obstacle generation, score progression and increasing speed over time.

The focus of the project is accessibility, optimization and mobile gameplay readability.

## Learning Objectives

- Understand basic 3D level construction.
- Implement procedural obstacle generation.
- Learn mobile gameplay constraints.
- Optimize rendering and performance.
- Manage game pacing and difficulty progression.
- Build clean UI systems for score and menus.

## Technical Requirements

### Mandatory Features

- Endless gameplay loop.
- Lane switching system.
- Procedural obstacle spawning.
- Score system.
- Increasing game speed.
- Main menu.
- Restart system.
- Mobile-oriented controls.

### Bonus Features

- Character skins.
- Dynamic environments.
- Day/night cycle.
- Object pooling optimization.
- Mobile haptic feedback.
- Collectibles.
- Achievement system.
